# NexusPlay
Plataforma web de recomendación de videojuegos desarrollada con React, Spring Boot y MySQL.

## Tecnologías utilizadas

- React
- Spring Boot
- MySQL
- Docker
- RAWG API

## Arquitectura

Frontend → React
Backend → Spring Boot
Base de datos → MySQL
Contenedores → Docker

## Ejecución con Docker

```bash
docker compose up --build
